Documentation

How to use it

  1. Open this page in the browser where you want to keep files.
  2. Enter the vault passphrase and choose UNLOCK.
  3. Add files with the drop zone, download them with GET, and remove them with DEL.
  4. Choose SEAL VAULT when you are done.

Where files live

Files are stored only in this browser's IndexedDB database (zencrypt_db), on this device. Clearing site data removes them. They are never uploaded to a server by this page.

GitHub Pages deployment

Upload this folder as-is. The site needs only static hosting: index.html is the entry point, and 404.html keeps direct links working on project pages. Keep the repository private if the file contains a demo passphrase.
